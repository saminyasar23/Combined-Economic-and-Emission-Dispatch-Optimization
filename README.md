### Project Description

This project focuses on optimizing the operation of multiple power-generating units through Combined Economic and Emission Dispatch. The objective is to determine the most efficient generation schedule that meets system load demand while minimizing both fuel costs and harmful emissions.

The optimization considers generator capacity limits, power balance, and operational constraints. By analyzing the trade-off between economic performance and environmental impact, the project supports cleaner, more cost-effective, and reliable power-system operation.
